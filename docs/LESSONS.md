# Уроки прошлых игр («Плот», «Эхо», «Ветра», «Петля»)

Читать перед новой игрой. Инфраструктура и шаблоны — в этом репозитории (он новее всех).

## Инструменты
- Ставить через `cargo install` (lune 0.11.1, rojo 7.7.1, selene 0.31.0, stylua 2.6.0 с `--features luau`); selene — **без** `--no-default-features`. API dump — с raw.githubusercontent.com (`MaximumADHD/Roblox-Client-Tracker`).
- stylua иногда падает на `a // b` внутри таблиц — писать `math.floor(a / b)`; не всегда стабилен — запускать дважды.
- Долгие прогоны на заглушке — в лог-файл в фоне, не через `| tail`; не делать `pkill -f` с шаблоном из собственной команды.

## Lune и заглушка движка (tests/engine/Sim.luau)
- В Lune нет `Part.Position` — читать `part.CFrame.Position` (и в игровом коде тоже, если он гоняется на заглушке).
- Сигналы хранить с сильными ключами; `implementProperty` не переопределяет настоящие свойства; свойства только для чтения (Seat.Occupant, Camera.ViewportSize) в Lune можно просто записать.
- Некоторые свойства без значения по умолчанию (например `Player.CameraMinZoomDistance`) падают при чтении — оборачивать в `pcall`.
- В Sim `task.delay` идёт в реальном времени. Игровую логику на `task.delay` не держать: отложенное (разморозка, таймеры, окна) — в шаге сервера по `GetServerTimeNow`.
- События, отправленные до того, как клиент подписался, на заглушке теряются (и в игре это ненадёжно): клиент при старте шлёт `sync`, сервер присылает текущее состояние.

## Луау
- `#t` у таблицы с «дырами» не определён: очередь BFS с `queue[i] = nil` ломается — держать явные `head/tail`.
- В RemoteEvent не слать таблицы с дырявыми числовыми ключами (`ev[шаг] = ...`): упаковывать списком `{ {шаг, ...} }`.
- Не называть дочерние объекты как свойства (TextLabel «Name» внутри объекта ломает `obj.Name`).

## Roblox
- `Workspace.StreamingEnabled = false`, `Players.CharacterAutoLoads = false`, спавн после постройки мира.
- Событие сервера может прийти раньше реплицированного атрибута: состояние UI — из событий и позиции персонажа, атрибуты только как подсказка.
- Отклик управления: если важна мгновенность, клиент двигает своё сам, сервер проверяет.
- Студийный Command Bar / Studio MCP `execute_luau` делает свой `require` — **отдельная копия модулей**. Отладка — через `workspace:SetAttribute("DebugCommand", "...")` и команду `state`, которая печатает состояние.
- Фильтр чата Roblox режет цифры и часть слов у детей до 13: не строить механики на передаче кодов через чат.
- Голосовой чат — только 13+ с проверкой возраста; запретить Discord нельзя — механики не должны ломаться от внешнего голоса.

## Дизайн и баланс
- Тест баланса на ботах писать сразу вместе с логикой (в «Эхе», «Ветрах» и «Петле» он находил дефекты до Studio). Сравнивать с базовыми политиками: «ничего не делает», «наугад», «новичок с медленной реакцией». Разрыв в мастерстве мерить; «бездействие» не должно быть выгодным.
- Одна «голова» бота: для чистой модели, для персонажей на заглушке и для ИИ/подсказки в игре.
- Если уровни генерируются и проверяются дорогим решателем — подбирать seed'ы скриптом офлайн, хранить в коде, тест проверяет каждый; после правки генератора/модели — перезапустить скрипт.
- Скуку ожидания мерить ботом (самое долгое ожидание, среднее за раунд) и ограничивать тестом.
- Числа в README брать из вывода тестов, не придумывать.

## Монетизация
- Косметику по умолчанию применять сразу, не дожидаясь профиля (DataStore может грузиться 10 с).
- Пока открыто окно оплаты developer product, связанный таймер не должен истечь (продлевать один раз).
- Платные случайные награды: точные шансы на экране (сумма ровно 100%), PolicyService (ошибка = запрещено), сервер сам не открывает промпт; для запрещённых регионов — прямая покупка.
- Не делать ставок покупаемой валютой на случайный исход — это выглядит как азартная игра.

## Интерфейс
- HUD на телефоне не меньше 0.75; проверять раскладку на 667×375 и при масштабе 1.25 тестом (прямоугольники с учётом UIScale предков: всё на экране, без наложений).
- Соседние виджеты — в один масштабируемый контейнер; большие окна вписывать в экран; на узком экране отдельная раскладка, левый низ свободен для стика.
