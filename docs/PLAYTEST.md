# Плейтест «Петли»: что проверить в Studio

40–50 минут. Порядок: запуск → первая петля → призрак и тень будущего → передача двери → ключ и парадокс → петли кончились → телефон → вдвоём → магазин → отладка.
Всё, что на заглушке движка проверить нельзя (настоящая ходьба персонажа, коллизии дверей, камера, свет, вид призраков, ощущение темпа), — здесь.

## 0. Запуск (3 мин)
```powershell
git pull
rokit install
rojo build -o game.rbxl
```
Открой `game.rbxl`, **View → Output**, **Play** (F5).
- [ ] Через 1–2 с ты стоишь на **часовом круге** (старт) уровня 1, вокруг — тёмно-синие комнаты со стенами с неоновой кромкой, вдали — золотистое хранилище с кристаллом.
- [ ] В Output нет красных строк. Есть `[World] ready in … s, 30 levels`.
- [ ] Через ~6 с: `[SELFTEST] RESULT 9/9 passed`. Ожидаемые WARN: `products configured` (ID = 0), `player data saves` (если не включён доступ к API) и `ghosts replay deterministically` (призраков ещё нет; после первой ⟲ нажми DBG → Self-test — станет PASS). Если есть FAIL — пришли строку.
- [ ] Сверху **LOOP 1 / 2** (или ПЕТЛЯ 1 / 2), две точки, шкала времени бежит, справа цифры 15.0 → 0.0. Слева — «Уровень 1 ☆☆☆», «Нужно «тебя»: 2», монеты. Под шкалой — подсказка обучения.

## 1. Первая петля и ⟲ (5 мин) — главное ощущение
| Что | Проверь |
|---|---|
| Ходьба | WASD: персонаж ходит сразу, без задержки. Прыжка нет (пробел ничего не делает). |
| Камера | Видно уровень сверху-сбоку, золотые ★-плиты и двери различимы. **Хватает ли обзора?** Если нет — запиши, сколько комнат не видно. |
| Плита | Встань на **золотую ★-плиту**: она проседает и светится, лампа над дверью хранилища загорается (1/1), дверь становится прозрачной. Сойди — через 0,3 с дверь снова закрыта. |
| ⟲ | На плите нажми **R**: персонаж замирает, кнопка ⟲ гаснет, сразу «Перемотка…», 1,2 с — и петля 2. Не ждёшь 15 с. |
| Петля 2 | Рядом с тобой **оранжевый призрак с цифрой 1** и кольцом под ногами идёт ровно туда, где ты был, и встаёт на плиту. Перед ним — **бледная тень на 1,5 с впереди** и пунктир. На двери хранилища надпись **«через 0.7»**, пока призрак не дошёл. |
| Победа | Пока призрак на плите, войди в хранилище и коснись кристалла: **ХРАНИЛИЩЕ ВСКРЫТО!**, ★★★, монеты, «Дальше (6)». Через 6 с — уровень 2. |
| **Понятно ли без объяснений**, что призрак — это ты из прошлой петли? Что надо сделать в петле 2? |

## 2. Передача двери (уровень 4, 7 мин) — головоломка
DBG → **Next level** до уровня 4 (или «Уровни» → 4 после «Unlock all»).
- [ ] Цветная дверь (например бирюзовая ◆) открыта, только пока кто-то стоит на ◆-плите; знак над дверью и на плите совпадает.
- [ ] Попробуй «по-новичковски»: петля 1 — встань на ◆ и **⟲** (призрак будет держать дверь вечно); петля 2 — дверь открыта, но золотую ★ держать некому, хранилище закрыто — **«Петли кончились»**. Окно с отсчётом 12 с, кнопки «↶ Отменить петлю» и «+1 петля · R$ 19».
- [ ] ↶: петля 2 стирается, снова петля 2. **Правильно:** петля 1 — постой на ◆ пару секунд (смотри на шкалу и цифры), потом беги на ★ и ⟲; петля 2 — успей проскочить дверь, пока призрак держит. **Догадался ли сам?** Сколько попыток?
- [ ] На шкале сверху метки: ■ — когда призрак закончил петлю, ◆/★ — когда откроются двери. Помогают ли?
- [ ] Если долго не выходит: **💡 Подсказка** (H) — белый силуэт идёт по решению. Монеты списались один раз (40), подсказка ставит не больше ★.

## 3. Ключ и парадокс (уровень 3 и 13, 6 мин)
- [ ] Уровень 3: ключ берётся, когда наступаешь (тост «Ключ у тебя»), над головой висит золотой ключ. Подойди к оранжевой двери с ⚿ — «Замок открыт», дверь открыта до конца петли.
- [ ] Петля 1: возьми ключ, отопри замок, встань на ★, ⟲. Петля 2: **беги к ключу раньше призрака**. Призрак **рассыпается**: красная вспышка, осколки, серый силуэт, ✕ на полу, крупно «ПАРАДОКС! Петля 1: ключ уже взят», звук. Он больше не стоит на плите (лампа гаснет).
- [ ] ↶ (Z) — всё возвращается, призрак снова целый.
- [ ] Уровень 13 (два ключа): видна иконка 🔑 там, где призрак возьмёт ключ в ближайшие 3 с.
- [ ] **Ясно ли правило парадокса** по одному случаю? Не кажется ли наказание несправедливым?

## 4. Петли кончились и «Лишняя петля» (3 мин)
- [ ] DBG → **Out of loops**: окно с отсчётом. Нажми «+1 петля»: в Studio — «Studio: покупка эмулирована», «+1 петля на этом уровне!», игра продолжается, сверху «ПЕТЛЯ 3 / 3».
- [ ] Ещё раз Out of loops и ничего не жми: через 12 с «Петля N стёрта», игра идёт дальше.
- [ ] (С настоящим ID товара, после публикации) окно ждёт, пока открыт промпт оплаты (отсчёт прыгает до 30 с один раз).

## 5. Телефон (5 мин)
**Test → Device** (эмулятор) → маленький телефон (iPhone SE) горизонтально, затем планшет.
- [ ] Стик слева работает, **кнопки прыжка нет**. Справа снизу большая **⟲ ПЕРЕМОТКА** под большой палец, над ней ↶ / ↺ / 💡.
- [ ] Шкала петли прижата вправо и не налезает на «Уровень / монеты» слева; подсказка обучения — под шкалой справа. Левый низ свободен для стика.
- [ ] Окна «Уровни», «Магазин», победа, «петли кончились» целиком на экране, листаются пальцем.
- [ ] Номера над призраками читаются.

## 6. Вдвоём (7 мин)
**Test → Clients and Servers**, 2 игрока → **Start**.
- [ ] У каждого свой уровень. Во втором окне «Вместе» → строка «Player1 · уровень 1 · 1/4» → «Войти». Второй игрок появляется на старте, замерший: «Ты войдёшь в уровень со следующей петлёй»; видит текущих призраков.
- [ ] Следующая петля: оба живые, сверху бюджет поделился (на уровне k=4 — «ПЕТЛЯ n / 2»). Игроки проходят друг сквозь друга.
- [ ] Оба нажали ⟲ → петля кончилась сразу. Следующая петля: **два призрака**, над каждым номер и имя («2 · Player2»).
- [ ] Один держит цветную плиту вживую — второй проходит дверь (в кооперативе передачи можно делать в реальном времени).
- [ ] Облик призраков, купленный одним, виден второму (материал/акцент призрака, след за персонажем).
- [ ] Второй выходит (закрой окно): у первого тост «… вышел — его призраки остаются».

## 7. Магазин (5 мин)
- [ ] DBG → «+1000 coins», «Облик» → купи «Стекло»: в следующей петле твой новый призрак стеклянный. След «Огненный» — за персонажем огненный след.
- [ ] **Капсула:** у каждого предмета процент, сверху 60 / 28 / 10 / 2. «Открыть» → окно с предметом; дубликат пишет «+N монет».
- [ ] **Пропуска:** VIP → золотой облик доступен, над головой ★ VIP. Оракул → подсказка бесплатна, пунктир призраков — до конца петли. «R$ 49» у редкого → «Studio: покупка эмулирована».
- [ ] Эффект перемотки (например «Часы»): в конце петли на месте твоих тел вспыхивают кольца этого цвета.

## 8. Отладка (2 мин)
- [ ] DBG: Autoplay (сервер сам проходит уровень по решению — смотри, как это выглядит), Win now, Next/Prev level, Out of loops, Undo, Restart, Unlock all, +1000 coins, Reset profile, Self-test, RU/EN.
- [ ] FPS (**View → Stats** или Ctrl+Shift+F5) на уровне 25+ с 4 призраками.

## Как прислать обратную связь
```
SELFTEST: (строки с FAIL/WARN)
Красные строки из Output: (если есть)
Ходьба: отклик ок / задержка; камера: видно уровень да / нет
Призрак понятен без объяснений: да / нет; тень будущего и пунктир: помогают / мешают / не замечены
Передача двери (уровень 4): догадался сам за __ попыток / нужна подсказка
Парадокс понятен: да / нет; что непонятно:
Скука: где приходилось стоять без дела и сколько
Телефон (эмулятор): кнопки __, шкала __, наложения __
Вдвоём: вход со следующей петли __, общие призраки __
Что сломано:
```
