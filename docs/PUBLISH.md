# Публикация и монетизация «Петли»

Общий путь «код → Studio → публикация → открыть для всех» тот же, что в `roblox/docs/PUBLISH.md` (аккаунт старше 2 дней, проверка возраста, анкета Maturity & Compliance, Manage Audience). Здесь — только то, что отличается: товары, ID, настройки места.

> Меню Creator Hub и Studio часто переименовывают. Если пункт называется иначе, ищи по смыслу; официальные страницы: [Passes](https://create.roblox.com/docs/production/monetization/game-passes), [Developer products](https://create.roblox.com/docs/production/monetization/developer-products), [PolicyService](https://create.roblox.com/docs/reference/engine/classes/PolicyService).

## 1. Первая публикация (приватно)
1. `rojo build -o game.rbxl`, открой в Studio.
2. **File → Publish to Roblox** → новая игра. Название и описание — ниже.
3. Creator Hub → игра → **Places** → стартовое место → **Server size: 12** (до 12 одиночных уровней или 3 группы по 4).
4. В Studio: **Game Settings → Security → Enable Studio Access to API Services** — иначе в Studio профиль не сохраняется (самотест покажет WARN `player data saves`).
5. **Game Settings → Avatar**: R15, анимации по умолчанию.

С этого момента работай с облачным местом: Creator Hub → **Edit in Studio** → `rojo serve` → **Connect**.

## 2. Товары: создать и вписать ID
Creator Hub → игра → **Monetization**.

### Геймпассы (Passes → Create a Pass)
| Ключ в `Config.Passes` | Название | Цена (рекоменд.) | Иконка |
|---|---|---|---|
| `Oracle` | Oracle / Оракул | 199 R$ | глаз из часового циферблата, белый силуэт |
| `DoubleCoins` | ×2 Coins / ×2 Монеты | 149 R$ | две золотые монеты с петлёй ⟲ |
| `Vip` | VIP | 249 R$ | золотой призрак со звездой |

После создания: вкладка **Sales** → **Item for Sale** → цена → Save. ID — в адресе страницы пасса или в меню «…» → **Copy Asset ID**.

### Developer Products (Developer Products → Create)
| Ключ в `Config.Products` | Название | Цена (рекоменд.) |
|---|---|---|
| `ExtraLoop` | Extra loop / Лишняя петля | 19 R$ |
| `Coins500` | 500 coins | 25 R$ |
| `Coins3000` | 3000 coins | 99 R$ |
| `Chest` | Time Capsule / Капсула времени | 35 R$ |
| `DirectRare` | Rare item / Редкий предмет | 49 R$ |
| `DirectEpic` | Epic item / Эпический предмет | 99 R$ |
| `DirectLegendary` | Legendary item / Легендарный предмет | 199 R$ |

### Вписать ID
`src/shared/Config.luau`:
```lua
Config.Passes = {
	DoubleCoins = { id = 123456789, robux = 149 },
	...
}
Config.Products = {
	ExtraLoop = { id = 987654321, robux = 19 },
	...
}
```
`robux` — запасная цена для интерфейса: игра сама запрашивает настоящую цену у Roblox (`GetProductInfo`), так что менять цену можно только в Creator Hub.

**Пока ID = 0:** в Studio покупка эмулируется (тост «Studio: покупка эмулирована»), в живой игре кнопка показывает «скоро». Самотест выводит WARN со списком товаров без ID.

**«Лишняя петля» и окно оплаты.** Когда петли кончились, окно ждёт 12 с, потом само стирает последнюю петлю. Если игрок нажал «+1 петля», сервер **один раз** продлевает окно до 30 с — пока открыт промпт оплаты, оно не истечёт. Покупка даёт +1 «тебя» на текущем уровне (за уровень тогда максимум ★). Проверь в живом клиенте: открыть промпт, подождать 15 с, оплатить — игра продолжается.

**Почему решение не продаётся.** Лишняя петля и подсказка облегчают уровень, но звёзды за него ниже (★), а ★★★ — только за чистое прохождение. Платное — внешний вид (видят все), удобство (подсказки «Оракула») и монеты.

## 3. Капсула и правила Roblox о случайных наградах
Уже сделано в коде:
- шанс **каждого** предмета показан до покупки (вкладка «Капсула»), сумма ровно 100%: Common 60% · Rare 28% · Epic 10% · Legendary 2%;
- дубликат превращается в монеты, сумма показана заранее;
- сервер спрашивает `PolicyService:GetPolicyInfoForPlayerAsync`; если `ArePaidRandomItemsRestricted` или запрос упал, капсула скрыта и сервер **отказывается** открыть промпт; остаётся прямая покупка любого предмета за монеты и за Robux.

Что сделать тебе:
- в анкете **Maturity & Compliance** честно отметить **платные случайные предметы** (paid random items), если такой вопрос есть; насилия и страшного нет — ожидаемый рейтинг Minimal;
- если меняешь шансы в `Config.Rarity`, запусти `lune run tests/run.luau`: тест не даст сломать сумму 100%.

## 4. Robux и Беларусь
DevEx недоступен, Robux копятся на балансе. Их выгоднее всего тратить на рекламу (Ads Manager → спонсорские показы) в первые недели: без игроков монетизация не работает. Механику отлично объясняет 10-секундный ролик без слов: «игрок встаёт на плиту → перемотка → рядом его копия → вдвоём открывают хранилище». Для ролика: DBG → Autoplay на уровне 9 или 22.

## 5. Страница игры
**Название:** `Loop: Heist With Yourself` (EN), `Петля: ограбление с самим собой` (RU — через Creator Hub → Localization).

**Описание (EN):**
> Every loop lasts 15 seconds. Then time rewinds — and the YOU from the last loop walks beside you, repeating every step. Hold the door for your future self, carry the key to the lock, stand on the gold plates together and crack the vault. But never steal from your past self: break its recording and it shatters — PARADOX! 30 handmade-by-code levels, solo or co-op with friends (everyone's ghosts are shared).

**Описание (RU):**
> Петля длится 15 секунд. Потом время откатывается — и рядом идёт ТЫ из прошлой петли, повторяя каждый шаг. Держи дверь для будущего себя, неси ключ к замку, вставайте на золотые плиты вместе и вскрывайте хранилище. Только не мешай прошлому себе: сломаешь его запись — он рассыплется, ПАРАДОКС! 30 уровней, один или с друзьями (призраки всех игроков общие).

**Жанр:** Puzzle (или Adventure). **Иконка 512×512:** три полупрозрачные фигуры разных цветов с цифрами 1, 2, 3 на золотых плитах, по центру — открытая дверь хранилища с кристаллом, сверху стрелка ⟲. **Скриншоты 1920×1080:** призрак с тенью будущего и пунктиром; цветная дверь с надписью «через 2.1»; парадокс (осколки, ✕); вскрытое хранилище и панель ★★★; кооператив — четыре призрака с именами; магазин с шансами. DBG → Autoplay помогает собрать кадр.

## 6. Перед открытием для всех
- [ ] Все ID вписаны, самотест без FAIL и без WARN о товарах.
- [ ] Покупка каждого товара проверена в живом клиенте (Creator Hub → Play) с тестовым аккаунтом; Robux списываются, товар выдаётся один раз.
- [ ] «Лишняя петля»: окно ждёт оплату; после оплаты петля начинается. «Оракул»: подсказка бесплатна, пунктир до конца петли. VIP: золотые призраки, табличка.
- [ ] Перезаход: монеты, звёзды, облик на месте; игрок начинает со следующего непройденного уровня.
- [ ] Server size = 12. Проверено на телефоне (живой клиент, не только эмулятор): ⟲ под большим пальцем, номера призраков читаются.
- [ ] Кооператив в живом сервере: вход со следующей петли, призраки общие, двери/плиты одинаковые у обоих.
